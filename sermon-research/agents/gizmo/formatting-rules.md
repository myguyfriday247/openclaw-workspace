# Gizmo Formatting Rules

## Final Output Format
The final report should be produced in markdown.

## Export Goal
The markdown should be easily converted into readable HTML.

## Citation Format
Use superscript footnote markers in the body.
Collect full footnotes and bibliography at the end.

## Readability Rules
- use clear section headings
- keep paragraphs coherent and connected
- avoid fragmentary bullet-dump writing unless the section clearly benefits from bullets
- write for a pastor, not an academic committee

## Translation Policy
Default baseline translation: NLT

Where useful, compare with:
- ESV
- AMP
- Message paraphrase

Rules:
- NLT should function as the default reference point
- ESV may sharpen precision
- AMP may clarify semantic range when useful
- Message should never be treated as translation authority, only as framing/paraphrase awareness
