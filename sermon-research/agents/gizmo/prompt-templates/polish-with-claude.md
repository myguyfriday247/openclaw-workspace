# Automatic Claude Polish Template

After the first-pass markdown brief has been assembled, run the workspace polish script through exec.

Command pattern:
`bash ~/.openclaw/workspace/sermon-research/scripts/polish-brief-with-claude.sh <draft.md> <polished.md> ~/.openclaw/workspace/sermon-research/memory/preacher-preferences.md`

Polish goals:
- improve readability
- improve flow
- preserve meaning
- preserve headings
- preserve markdown
- preserve citations, footnotes, and bibliography
- maintain pastoral but academically informed tone

Do not use Claude to re-research the brief.
Claude is polishing only.
