SermonDev, semester/series planning, church leadership

🤖 Personal Assistant

Research, scheduling, reminders, information retrieval

2. Current State Assessment

✅ What We Have

  • Mission Control - Main dashboard with sidebar navigation
  • SermonDev - Full process docs + dashboard for sermon/series/semester planning
  • CommTracker - React/Next.js app for church communications tracking
  • Cron Jobs - Scheduled tasks (daily digest, receipt scanning, semester planning)
  • Memory System - Daily logs, progress tracking, project docs

⚠️ What Needs Improvement

  • No centralized Task Board - can't see what agent is working on
  • No visual Calendar view of scheduled tasks
  • No Projects dashboard for major initiatives
  • Documents get lost in chat history
  • No Team/Agent architecture visualization
  • Not using Discord (still on webchat)
  • Memory is fragmented across files

🎯 Key Insights from Expert

  • Task Board - Full visibility into agent work
  • Multi-channel Discord - Separate channels for each project/area
  • Sub-agents - Specialized agents for specific tasks
  • Reverse prompting - Ask AI what tools to build
  • Documents screen - All generated docs organized and searchable

4. Mission Control Tabs

Proposed tab structure for the left sidebar:

🔴 Priority: Task Board

Kanban board showing all tasks across all areas. Who (me/agent) owns each task. Live activity feed. Drag to move, review column for my approval.

🔴 Priority: Calendar

Visual calendar showing all cron jobs, scheduled tasks, upcoming sermons, deadlines. Verify agent is actually scheduling things.

🟡 Projects

Major initiatives tracked: CommTracker v2, Sermon Series, Discipleship Book, etc. Progress, related docs, tasks per project.

🟡 Documents

All generated documents organized: sermons, plans, research, content. Searchable. Every doc AI creates goes here.

🟢 Memories

Organized memory interface. Browse by day. Long-term memory section for persistent knowledge.

🟢 Team

Visual org chart of all agents. Their roles. Mission statement. Direct lines to each sub-agent.

Existing Tabs to Retain/Improve

  • Dashboard - Keep as overview
  • Docs - CommTracker docs, keep
  • Ideas - CommTracker suggestions, keep
  • SermonDev - Rebuild with new structure
