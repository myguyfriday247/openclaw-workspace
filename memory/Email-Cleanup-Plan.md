# Email Cleanup Plan

_A step-by-step guide to declutter your inbox_

---

## Phase 1: Assessment (15 min)

### Step 1: Identify Clutter Sources
1. Search for "unsubscribe" in your inbox
2. Look for patterns:
   - Newsletters you never read
   - Marketing emails
   - Notifications you don't need
   - Daily digests that pile up

### Step 2: Categorize
Create folders/labels:
- **Unsubscribe** — These go
- **Maybe** — Review later
- **Keep** — Important only

### Step 3: Count
- How many unsubscribe candidates?
- How many newsletters?
- How many marketing emails?

---

## Phase 2: Bulk Unsubscribe (20 min)

### Tools Available

**Option A: Microsoft Outlook Built-in**
1. Select all newsletters
2. Click "Unsubscribe" (appears in toolbar)
3. Or: Right-click → "Unsubscribe"

**Option B: Leave Me Alone**
- Visit: https://leavemealone.app
- Connect inbox
- Shows all subscriptions in one view
- One-click unsubscribe

**Option C: CleanEmail**
- Visit: https://cleanemail.com
- Similar to Leave Me Alone
- Good for Office 365

**Option D: Manual**
1. Scroll to bottom of each newsletter
2. Click "Unsubscribe" link
3. Confirm (may take 2-3 clicks)

---

## Phase 3: Create Rules (10 min)

### Rules to Set Up

**Rule 1:** Move social notifications to "Social" folder
- Facebook, LinkedIn, Twitter/X

**Rule 2:** Move marketing to "Promotions" or delete
- Amazon, Groupon, etc.

**Rule 3:** Flag newsletters for weekend reading
- Create "Read Later" folder

**Rule 4:** VIP filter
- Key contacts → Starred or VIP

---

## Phase 4: Prevention (Ongoing)

### New Rules
1. **Think before subscribing** — "Will I actually read this?"
2. **Use burner email** — For non-essential signups
3. **Weekly review** — 10 min Sunday evening
4. **Unsubscribe reflex** — When in doubt, unsubscribe

### Quick Unsubscribe
- Use browser extension: "Unroll.me" or similar
- Shows all subscriptions in one click

---

## Quick Checklist

- [ ] Search "unsubscribe" — find candidates
- [ ] Count newsletters vs. important emails
- [ ] Pick tool (Outlook, Leave Me Alone, CleanEmail)
- [ ] Bulk unsubscribe (20-30 min)
- [ ] Set up 3-4 inbox rules
- [ ] Schedule weekly 10-min review

---

## Recommended Workflow

**Weekly (Sunday 8pm, 10 min):**
1. Search "unsubscribe" for new clutter
2. Apply quick rules
3. Move to "Read Later" folder
4. Delete promotional without opening

**Monthly (First Sunday, 30 min):**
1. Review "Read Later" folder
2. Unsubscribe from anything skipped twice
3. Update rules as needed
