# Project Brief: Gospel Share Tracker

---

## Project Name
Gospel Share Tracker

## Description
A web-based application for tracking gospel sharing activities across a church or ministry team. Allows members to log:
- How many people they shared with
- Types of interactions (church invitation, spiritual conversation, story share, gospel presentation)
- Gospel responses
- Notes and stories

## Success Definition
- Team members can easily log their sharing activities
- Admins can view aggregated data across the team
- Export functionality for reporting
- Import functionality for bulk entry

---

## Phases (Ordered)

### Phase 1: Data Model ✅ Complete
- Supabase database setup
- People table with user linking
- Gospel share entries table
- Authentication flow

### Phase 2: Admin Portal ✅ Complete
- People management
- User management
- Export to CSV
- Import from CSV

### Phase 3: Import/Export ✅ Complete
- CSV export for all data
- CSV import with validation
- Preview before import
- Error handling

### Phase 4: Invitations 🔄 In Progress
- Invitation tracking feature
- Link invitations to specific people
- Response tracking for invitations

### Phase 5: UX & Quality
- Dashboard improvements
- Mobile responsiveness
- Performance optimization
- Accessibility

---

## Known Assumptions & Risks

- Users have basic tech literacy
- Supabase handles authentication
- No real-time collaboration required initially
- Data stays within reasonable limits for free tier
